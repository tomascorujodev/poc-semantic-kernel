# Returns Policy

## Return window
Customers can return most products within 30 days of delivery. The return window for items bought during the Black Friday sale is extended to 60 days.

## Condition of returned items
Unopened products get a full refund. Opened laptops, tablets and monitors have a 15% restocking fee. Opened accessories (cables, docks, keyboards) can be returned without a fee.

## Non-returnable items
Headphones and earbuds cannot be returned once opened, for hygiene reasons. Software licenses and gift cards are also non-returnable.

## How to start a return
Customers start a return from "My orders" on the website or by contacting support with the order id. Return shipping is free for defective items; otherwise the customer pays 9.90 EUR.

## Refunds
Refunds go back to the original payment method within 7 business days after the warehouse receives the item.
